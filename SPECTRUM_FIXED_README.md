# Axel Spectrum / Fixed

Откройте `spectrum-analyzer-fixed.html` в Edge или Chrome. Это отдельная самостоятельная страница варианта «OpenAI API + загруженный готовый Python-скрипт». Предыдущая `spectrum-analyzer.html` продолжает использовать Python, создаваемый моделью.

## Использование

1. Выберите TXT и формат: DTR либо один отсчёт на строку.
2. Задайте реальную Fs, диапазон поиска и ширину сглаживания. По умолчанию FWHM=0.02 Гц: максимумы ближе 0.02 Гц объединяются. Значение 0 отключает сглаживание. Для записи 20260625 из этого проекта Fs=100 Гц и диапазон на скриншоте 0.1–10 Гц.
3. Введите API key. По умолчанию выбраны `gpt-5.6-luna`, reasoning `low`, лимит выходных токенов 32000.
4. Нажмите «Анализировать». Страница загружает `input.txt`, `spectrum-fixed.py` и `settings.json` в новый контейнер. Модель получает короткую команду запуска скрипта через Code Interpreter.
5. Скачайте `analysis.json`, `spectrum.csv`, `analysis.py` и `settings.json`. Python заранее встроен в HTML; устанавливать Python на своём компьютере для работы страницы не требуется. Кнопка «Скачать исходный .py» доступна до запуска.

«Открыть JSON» открывает ранее сохранённый спектр без API-запросов. При таком просмотре проверяется структура файла, но происхождение данных не подтверждается; CSV и скрипт не восстанавливаются из JSON. Комментарий пользователя сохраняется как заметка и не меняет алгоритм.

## Фиксированная методика v2.2.0

Зависимость скрипта — NumPy. Линейный тренд удаляется методом наименьших квадратов, затем применяется симметричное окно Ханна и rFFT длины N. Односторонняя пиковая амплитуда нормируется на сумму окна, DC и чётный бин Найквиста не удваиваются. Для численно нулевого остатка линейного detrend спектр обнуляется на уровне погрешности float64.

Линейная амплитуда FFT сглаживается гауссовым ядром; параметр в интерфейсе задаёт полную ширину на половине высоты (FWHM) в герцах. Кандидаты — локальные максимумы сглаженной кривой. После ранжирования применяется подавление соседних максимумов: внутри заданной ширины остаётся один кандидат с наибольшим контрастом. Для него `frequency_hz` и `amplitude` берутся у сильнейшего исходного FFT-бина в объединённой полосе, а сглаженный центр и уровень сохраняются отдельно.

Контраст считается по исходной амплитуде: фон — медиана в пределах ±50 бинов с исключением ±2 бинов, нижняя граница `max(A)*1e-10`; критерий — `20*log10(A_peak/A_background)`. Это не параметр prominence из SciPy и не статистическая значимость. После порога сохраняются до 80 пиков с наибольшим контрастом. Разные физические линии внутри FWHM намеренно считаются одним пиком; слишком большое значение может скрыть полезное разделение частот.

Гармонические группы — эвристика: наблюдаемая основная частота, не менее трёх различных порядков 1–12, допуск 1.5 шага FFT, уточнение f0 через регрессию частот по порядкам. Семейства не пересекаются; близкие источники, отсутствующая основная частота и случайная кратность могут дать ошибки. Временной анализ использует Hann-окна; трекинг ищет основную линию в пределах ±2 бинов окна. Ограничены число окон (1000) и суммарная работа (ориентир 16 млн отсчётов окон); при разреживании выдаётся предупреждение. Диапазон трекинга не является точной оценкой дрейфа.

На графике показывается сглаженный амплитудный спектр; дБ нормированы на его максимум в диапазоне. Подписи по умолчанию выбираются по локальному контрасту с разнесением по горизонтали. Селектор позволяет переключиться на абсолютную амплитуду исходного FFT-бина. Карточка «Максимум сглаженного» показывает максимум сглаженной кривой независимо от сортировки списка.

CSV содержит все бины 0…Fs/2 и колонки `frequency_hz,raw_amplitude,smoothed_amplitude`, а JSON — до 2400 последовательных групп с сохранением максимума сглаженной кривой. Пики вычисляются до уменьшения спектра для отображения. Единицы исходные, калибровка давления не предполагается. Фильтр FIR эта версия не рассчитывает.

## Проверка исполнения

Скрипт сверяет SHA-256 входного TXT и собственного кода с настройками. JSON записывается последним, содержит версию, ID запуска, хеши TXT/скрипта/настроек/CSV и версии Python/NumPy. Страница проверяет эти поля, схему результата и скачанный код/CSV. Это проверка согласованности файлов, не криптографическое доказательство исполнения: модель имеет доступ к контейнеру и результатам. Скрипт можно независимо повторно запустить локально.

Автоматического переписывания скрипта моделью при ошибках нет. Если ответ завершился с `max_output_tokens`, но Python успел завершиться и все файлы проходят проверки, результат принимается с записью в журнале. Без завершённого исполнения или полного набора проверяемых файлов результат отклоняется. Лимит токенов можно увеличить в форме; расходы зависят от реально использованного бюджета и контейнера.

API key хранится в памяти страницы. TXT отправляется в OpenAI. Для общей опубликованной страницы нужен серверный посредник, чтобы не раскрывать ключ. После окончания/ошибки/остановки страница удаляет созданный контейнер; повтор очистки доступен в журнале. Фоновый Responses-ответ остаётся сохранённым. Действуют ограничения базовой версии: TXT 20 МБ, JSON/скрипт 8 МБ, CSV 128 МБ, ожидание до 20 минут.

## Проверенная запись

`results/20260625/analysis.json` и `spectrum.csv` получены локальным исполнением того же скрипта над предоставленным TXT. N=162896, Fs=100 Гц, длительность=1628.96 с, df≈0.0006138886 Гц. При FWHM=0.02 Гц близкая пара 2.496/2.505 Гц представлена одним пиком 2.50527944 Гц. Среди наиболее контрастных линий также остаются 5.00135055, 4.25486200 и 8.53059621 Гц; точные значения доступны в JSON.

Ошибка предыдущего вида графика была в отборе 80 пиков и пяти подписей по абсолютной амплитуде, что отдаёт приоритет низкочастотному фону. После перехода к локальному контрасту появляются и ранее вытеснявшиеся компоненты, например около 9.316 и 9.994 Гц. Картинка: `results/20260625/spectrum-corrected.png`; экспорт SVG также сохранён.

## Проверки разработки

- `python qa/test_spectrum_fixed.py`: численные тесты, разбор TXT и регрессия выбора слабой линии над малым фоном.
- `node qa/spectrum-fixed.smoke.cjs`: перехваченный API с реальным локальным исполнением загруженного Python; проверка хешей, ошибок, скачивания, отмены и восстановления после лимита токенов.
- `python qa/analyze_record.py`: воспроизведение записи пользователя и сохранение файлов.
- `node qa/record-ui.cjs`: импорт реального результата в обе HTML-версии, проверка подписей, сортировки и мобильной ширины, экспорт графика.

Живой платный API-запрос в ходе этих проверок не выполнялся. При изменении `spectrum-fixed.py` обновляйте встроенную копию в HTML и версию; браузерный тест проверяет совпадение копий.

Документация: [Code Interpreter](https://developers.openai.com/api/docs/guides/tools-code-interpreter), [загрузка файла контейнера](https://developers.openai.com/api/reference/python/resources/containers/subresources/files/methods/create).
