# AI-Based Filter

Веб-инструмент для спектрального анализа TXT-логов и поиска гармонических составляющих. Вычисления выполняются фиксированным Python-скриптом в OpenAI Code Interpreter.

## Возможности

- удаление постоянной и линейно изменяющейся составляющей;
- амплитудный спектр с окном Ханна;
- гауссово сглаживание и объединение близко расположенных пиков;
- поиск гармонических семейств;
- экспорт результата в JSON и полного спектра в CSV;
- проверка версии и SHA-256 исполняемого Python-скрипта.

## Использование

Откройте опубликованную GitLab Pages-страницу, загрузите TXT-файл, задайте частоту дискретизации и диапазон анализа, затем введите собственный OpenAI API key. Ключ хранится только в памяти открытой страницы и не включён в репозиторий.

Исходный TXT-файл отправляется напрямую из браузера в OpenAI API. Запрос и вычисления оплачиваются владельцем введённого API-ключа.

## Локальный запуск

Откройте `spectrum-analyzer-fixed.html` в браузере. Если браузер ограничивает запросы из `file://`, запустите любой локальный статический HTTP-сервер в каталоге проекта.

Подробное описание алгоритма находится в `SPECTRUM_FIXED_README.md`.

## GitLab Pages

Файл `.gitlab-ci.yml` запускает численные тесты и публикует `spectrum-analyzer-fixed.html` как `index.html` из каталога `public`. Публикация выполняется только из основной ветки проекта.
